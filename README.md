# Wolf's design review board

An unlisted review page for the owners: 100 designs, six reference photos each (loaded from the search engine's thumbnail service, not stored here), with a rating, a closest-photo pick and a note per design. Answers stay in the reviewer's browser and are sent by email with the button on the page.

Built from the jewelry site's catalog by the build script kept in that project's session notes; regenerate and push to update.
